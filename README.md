# Daily Affirm ✨

A personalized daily affirmation app — build a positive mindset habit with uplifting notifications tailored to your life goals (Finance, Love, Career, Health, Mindset).

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | Vite + React + TypeScript + Tailwind CSS v4 |
| **Native Shell** | Capacitor 7 (iOS) |
| **Backend API** | Express.js + SQLite (better-sqlite3) |
| **Notifications** | Capacitor Local Notifications (native) + Push Notifications |
| **Auth** | Email login or guest (localStorage-persisted) |

## Quick Start (Web Development)

```bash
# Install all dependencies
cd client && npm install && cd ../server && npm install && cd ..

# Terminal 1: Start the backend API
cd server && npm run dev

# Terminal 2: Start the frontend dev server
cd client && npm run dev
```

Open http://localhost:5173 in your browser. The Vite dev server proxies `/api` requests to the Express server on port 3001.

## iOS App Store Build

### Prerequisites

- macOS with **Xcode 15+** installed
- **CocoaPods**: `sudo gem install cocoapods`
- An **Apple Developer account** ($99/year) for App Store distribution

### Setup

```bash
# 1. Install client dependencies (includes Capacitor + native plugins)
cd client
npm install

# 2. Build the web app and sync to iOS project
npm run build:ios

# 3. Open the iOS project in Xcode
npm run open:ios
```

In Xcode:
1. Select the **Daily Affirm** target
2. Go to **Signing & Capabilities** and select your Apple Developer team
3. Enable **Push Notifications** capability (should already be configured)
4. Set the **Bundle Identifier** (e.g. `com.dailyaffirm.app`)
5. Add your **App Icon**: Use the 1024x1024 master at `client/public/assets/app-icon.png`
6. Set the **Deployment Target** to iOS 16.0+

### Production API Server

The app needs a live backend API for production. You have two options:

**Option A: Host the Express server**
- Deploy `server/` to a service like Railway, Render, Fly.io, or a VPS
- Update `capacitor.config.ts` to set `server.url` to your deployed API URL

**Option B: Use the built-in seed data only** (offline mode)
- Modify the app to cache affirmations locally
- Works without a server for read-only use

### Building for the App Store

```bash
# 1. Production build
npm run build:ios

# 2. In Xcode:
#    - Product → Archive
#    - Distribute App → App Store Connect
#    - Follow Apple's submission flow
```

### Push Notifications Setup

For production push notifications:
1. In your **Apple Developer Account**, create a **Push Notification Key** (APNs key)
2. Configure push notification service on your backend or use a service like Firebase Cloud Messaging / OneSignal
3. The Capacitor PushNotifications plugin handles client-side registration automatically

## Features

- ✅ 5 life categories: Finance, Love, Career, Health, Mindset
- ✅ 3-step onboarding flow with illustrated screens
- ✅ Custom affirmation creation with category tagging
- ✅ 60 pre-written affirmations (12 per category)
- ✅ Notification scheduling (1x/3x/5x per day)
- ✅ Streak tracking
- ✅ Email or guest login
- ✅ Save/favorite affirmations
- ✅ Share affirmations
- ✅ Category filtering on home screen & library
- ✅ Calm, wellness-focused UI with soft gradients
- ✅ PWA support for web browsers
- ✅ Native iOS app via Capacitor

## Screens

- **Onboarding**: Welcome → Categories → Frequency → Login
- **Home**: Greeting, streak counter, category tabs, affirmation card, repeat/save/share
- **My Affirmations**: Create, edit, delete user affirmations
- **Create Affirmation**: Text input, category tags, notification toggle
- **Library**: Browse all affirmations, filter by category, save favorites
- **Settings**: Edit categories, frequency, notifications, streak reset, logout
