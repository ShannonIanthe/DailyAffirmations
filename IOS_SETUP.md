# Daily Affirm — iOS App

A mobile-first daily affirmation app, wrapped with Capacitor for native iOS deployment.

## Project Structure

```
daily-affirm/
├── client/              # Vite + React + TypeScript + Tailwind CSS frontend
│   ├── ios/             # Xcode iOS project (generated by Capacitor)
│   ├── public/          # Static assets
│   ├── src/             # React app source
│   │   ├── pages/       # Screen components
│   │   ├── components/  # Reusable UI components
│   │   ├── hooks/       # React hooks (useAuth)
│   │   └── lib/         # Utilities (api.ts, notifications.ts)
│   ├── capacitor.config.ts  # Capacitor configuration
│   └── package.json
├── server/              # Express.js API server
│   └── src/
│       ├── db.ts        # SQLite database
│       ├── seed.ts      # System affirmations (60 seeds)
│       └── routes/      # API route handlers
└── shared/              # Shared TypeScript types
```

## Prerequisites

- **macOS** (required for iOS development)
- **Xcode 15+** (from Mac App Store)
- **CocoaPods** (`sudo gem install cocoapods`)
- **Node.js 18+**
- **An iOS Developer Account** (Apple, $99/year — required for App Store publishing)

## iOS Setup & Build

### 1. Install dependencies

```bash
cd client
npm install
```

### 2. Build the web app & sync to iOS

```bash
npm run build:ios
```

This runs:
1. `tsc -b && vite build` — builds the React app to `client/dist/`
2. `npx cap copy` — copies web assets to the iOS project
3. `npx cap sync` — syncs Capacitor plugins to the iOS project

### 3. Open in Xcode

```bash
npm run open:ios
```

Or open manually:
```
client/ios/App/App.xcworkspace
```

### 4. Configure Signing in Xcode

1. Open the project in Xcode
2. Select the "App" target
3. Under **Signing & Capabilities**, select your team
4. Set a unique Bundle Identifier (e.g., `com.yourname.dailyaffirm`)
5. **Push Notifications** capability should already be enabled

### 5. Build & Run

- Select a simulator or connected device
- Press **Run** (⌘R)

## Running the Backend

The Capacitor iOS app wraps only the **frontend**. The Express API server must be running separately:

```bash
# From the project root
cd /path/to/daily-affirm
npm run dev:server
```

The API runs on `http://localhost:3001`.

### Production Deployment

For App Store distribution, you must deploy the Express API to a public server (e.g., Railway, Render, Fly.io, VPS) and update the API_BASE in `client/src/lib/api.ts` to point to your deployed server URL.

## Build Scripts

| Script | Purpose |
|--------|---------|
| `npm run build` | Build web app only |
| `npm run build:ios` | Build web + copy to iOS |
| `npm run open:ios` | Open Xcode project |
| `npm run sync:ios` | Sync Capacitor plugins |
| `npm run dev` | Run both dev server & client |

## Push Notifications (Local)

The app uses **`@capacitor/local-notifications`** to schedule daily affirmations at user-chosen times:
- **1x/day**: Morning (9:00)
- **3x/day**: Morning (8:00), Afternoon (13:00), Evening (19:00)
- **5x/day**: Morning (7:00), Late morning (10:00), Afternoon (13:00), Evening (17:00), Night (21:00)

## App Icon

Place your app icon assets in Xcode under:
```
App > Assets.xcassets > AppIcon
```
The designer can generate the required icon sizes.

## App Store Submission

1. Build the app for **Any iOS Device (arm64)** via Xcode
2. Archive the build (Product > Archive)
3. Upload to App Store Connect
4. Complete App Store Connect metadata (screenshots, description, privacy policy)
5. Submit for review

> **Note:** The Express backend must be publicly accessible before publishing, or the app will show "Cannot connect to server".

## Troubleshooting

- **CocoaPods errors**: Run `cd ios/App && pod install`
- **Plugin not found**: Run `npx cap sync` to re-sync plugins
- **Blank screen**: Ensure the API server is running at `localhost:3001`
- **Capacitor console logs**: Use Safari Web Inspector when running on a simulator/device
